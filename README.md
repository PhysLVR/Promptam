# Promptam — مدیریت پرامپت‌ها
یک PWA سبک و آفلاین برای مدیریت، دسته‌بندی و استفادهٔ سریع از پرامپت‌ها.
بدون بک‌اند، بدون ثبت‌نام — همهٔ داده‌ها در `localStorage` مرورگر کاربر.

## امکانات

- جست‌وجو و دستور سریع (کلید `/`)
- دسته‌بندی رنگ‌دار + تگ
- سنجاق کردن پرامپت‌های پرکاربرد
- متغیرهای `{{مثل این}}` با فرم پر کردن
- کپی یک‌کلیکی + باز کردن مستقیم در ChatGPT / Claude / Perplexity / Grok / Gemini / DeepSeek و…
- چند پوسته و پالت رنگ، اندازهٔ متن قابل تنظیم
- خروجی / ورودی JSON برای پشتیبان‌گیری
- قابل نصب روی اندروید (و iOS) به‌عنوان اپ مستقل
- بازخورد های صوتی
- کتابخانه آنلاین پرامپت
- کاملاً آفلاین بعد از بار اول
